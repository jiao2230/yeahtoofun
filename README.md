# 名箓 · Minglu

## 是什么

名箓是一个运行在本地电脑上的古典中文姓名生成器，面向修仙、历史题材的小说、游戏、跑团和私人设定。它不接大模型，不做命理，运行时不需要联网。

## 干什么

按时代、性别、风格、阶层生成「姓 + 名」，可选字辈；同一套数据、条件和 seed 可以复现同一个名字。时代分为秦汉、魏晋、唐宋、明清、仙侠；风格分为史实、写意、宗教；阶层分为雅士、俗人。

- 雅士走典雅、意象较好的用字；
- 俗人走通俗常见字、排行和小名式组合；
- 宗教名保证包含道、僧、法、德、正、元、玄、承、景、宗、真、之、弘、修、悟、子、智、贤、纯、中之一；
- 男性、女性用字意象分开；
- 输出附带拼音、声调、字义解释、用典、重名提示和 seed。

除人名外，也可生成宗门、丹药、功法和法宝名，均不带品阶。提供命令行、本地 HTTP 服务和 Web UI。

## 数据来源

- **CBDB 中国历代人物传记资料库**：历代姓名、朝代、性别与身份分布；授权 CC BY-NC-SA 4.0，仅个人非商业使用，不随包分发。
- **Chinese-Names-Corpus**：现代姓名用字频率、性别倾向、双字共现和姓氏；Apache-2.0。
- **chinese-poetry + 维基文库**：楚辞、诗经、论语、周易、庄子、唐诗、宋词用典与双字搭配；MIT/公版。
- **Unihan**：读音、部首、笔画；Unicode License。
- **项目词表**：风格字表、宗门/丹药/功法/法宝词表、正面与负面字表；项目自建。
- **公版古籍**：山海经、淮南子、本草纲目、云笈七签等，仅摘取词级意象。

数据包分 `seed`、`core`、`cbdb` 三档；`cbdb` 含非商业授权数据，只在本机构建使用。
