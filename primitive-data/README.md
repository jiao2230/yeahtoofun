# primitive-data

外部原始输入统一放在这里；本目录不作为发布数据提交。

## 文件

```text
魏晋南北朝名字.txt
出自汉魏南北朝墓志汇编.xlsx
明清女性姓名补充.xlsx
云笈七签人名.txt
诗词男性意象补充.docx
mqww202512.accdb
cbdb_20261024/
Chinese-Names-Corpus-master/
```

## 用途

- 论文、墓志、名表：作为人工整理来源；
- `mqww202512.accdb`：本地女性诗人/篇目索引；
- `cbdb_20261024/`：CBDB 原始库；
- `Chinese-Names-Corpus-master/`：现代姓名语料。

构建脚本的默认路径已指向本目录。`.accdb`、CBDB 和 CNC 语料不提交仓库。
